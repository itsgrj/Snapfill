# Demo forms

Three sample forms to try Snapfill without filling a real one. Open any of them in the browser where Snapfill is installed and click the first field.

| Form | What it shows |
|---|---|
| [event-registration.html](event-registration.html) | A first fill, and the password field it leaves alone |
| [job-application.html](job-application.html) | The same details under different labels, plus a field it learns |
| [guide-download.html](guide-download.html) | A one-off form, the place to try the Dummy profile |

Opening the files straight from disk needs one switch: on Snapfill's card in the extensions page, turn on **Allow access to file URLs**. Or serve the folder, for example with `python3 -m http.server`.
