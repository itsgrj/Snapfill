# Security

If you find a way for a website to read what Snapfill stores, or for Snapfill to fill a field it
should never touch, please report it privately using GitHub's
[private vulnerability reporting](https://github.com/itsgrj/Snapfill/security/advisories/new)
rather than a public issue.

Include the page or steps that show the problem, and what you expected Snapfill to do. You will
hear back within a week.
